# 🚀 Repositório de Estudos: Ciência de Dados, IA & Engenharia de Software

Bem-vindo(a)! Este repositório é dedicado à documentação prática, exercícios, simulados e projetos focados no aprofundamento de **Estruturas de Dados, Algoritmos, Bancos de Dados e Inteligência Artificial/LLMs**.

---

## 🎯 Objetivos de Aprendizado

- **Consolidar Algoritmos & Estruturas de Dados:** Implementação limpa e análise de complexidade temporal e espacial ($O(n)$, $O(n \log n)$).
- **Dominar Modelagem & Consulta de Dados:** Prática avançada em bancos relacionais e integração com dados vetoriais.
- **Desenvolver Soluções com LLMs & IA Conversacional:** Aplicação prática de técnicas modernas de Engenharia de Prompt, RAG e integração de APIs de IA.

---

## 📚 Conteúdo & Trilha de Estudos

### 💻 1. Código & Algoritmos
- [x] **Estruturas de Dados Principais:** Listas, dicionários, pilhas, filas e manipulação de coleções.
- [x] **Algoritmos Clássicos:** Busca binária, *Merge Sort*, *Quick Sort* e recursão.
- [x] **Análise Algorítmica:** Complexidade Big-O e otimização de código.

### 🗄️ 2. Banco de Dados & Armazenamento
- [x] **Relacional:** Modelagem SQL, criação de índices, joins complexos e agregações.
- [x] **ORMs & Frameworks:** Mapeamento objeto-relacional e otimização de consultas.
- [x] **Dados Vetoriais:** Busca por similaridade (ex: cosseno), embeddings e bancos orientados a vetores.

### 🤖 3. Inteligência Artificial & LLMs
- [x] **Fundamentos de LLMs:** Contexto, tokenização, embeddings e arquitetura Transformer.
- [x] **Engenharia de Prompt:** *Zero-shot*, *Few-shot*, *Chain-of-Thought* e mitigação de alucinações.
- [x] **Arquitetura RAG:** *Retrieval-Augmented Generation* integrada a bases de conhecimento.
- [x] **Agentes & Ferramentas:** *Function Calling*, consumo de APIs de IA e automação de fluxos.
