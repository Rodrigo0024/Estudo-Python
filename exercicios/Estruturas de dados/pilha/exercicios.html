Exercícios de Pilha

Qual método do Python adiciona um elemento ao final de uma lista?

append()

Qual método do Python remove o último elemento de uma lista?

pop()

O que é uma Pilha?

Uma pilha é uma estrutura de dados que segue o princípio LIFO (Last In, First Out), ou seja, o último elemento a ser adicionado é o primeiro a ser removido.
